## Projects

### [KronKollen](https://github.com/Edvin-Dyremark/KronKollen)
Local-first personal expense tracker for Android, built with Kotlin and Jetpack Compose (Material 3).
Import an `.xlsx` from your bank, map the columns once, and transactions are auto-categorized with keyword rules you control. Spending breakdowns with donut and monthly bar charts, full transaction table, and JSON backup/restore. All data stays on the device (Room), with Swedish (SEK) formatting. 
Built to replace personal and improve personal expenditure tracking previously done via excel.

### [Daily Wallpaper](https://github.com/Edvin-Dyremark/DailyWallpaper)
Android app that automatically sets your wallpaper on a schedule.
Fully customizable: pick which photos to draw from (albums, subsets, or all), choose how often wallpapers change (every X unlocks, every X hours, etc.), and target the lock screen, home screen or app drawer. Can overlay the location, date and album name onto the wallpaper. 
Built to fill the gap left by Google Photos, which can't randomly cycle wallpapers from your galleries, does not feature true random selection, and has lacking overlay settings even with available photo metadata. Also, i wanted more customizability. 

### [Dartz](https://github.com/Edvin-Dyremark/Dartz)
Dart scoring app for Android built with Kotlin and Jetpack Compose.
Features gamemodes 301, 501, Cricket, and Killer and an intuitive scoring system (no mental arithmetics required). 
Built for simple darts scoring mechanics without having to do any calculations urself.

### [Master Planner](https://edvin-dyremark.github.io/MasterPlanner/#/)

View, add and plan courses in an easy-to-use interface which detects clashes, course requirements and more. Made with Vue 3 and powered by Supabase for authentication and data storage. Built to assist in planning of my master studies in Secure Systems.
